### 🧑‍💻 About me

I build AI systems that people use in production. At **MASSINI Industries** (palletizers and packaging machinery) I designed and develop **ISAAC**, a RAG assistant that answers service technicians' and customers' questions using the documentation of each specific machine — manuals, electrical and pneumatic schematics, alarms and spare parts — and says so when the documents don't cover a question.

- 🔎 Hybrid retrieval with local ONNX embedding + reranker models, answers generated through the Claude API
- 📈 Right answer in the top 5 for 86% of 250 real questions, zero spare-part errors
- 🧪 533 automated tests, FastAPI backend, Streamlit UI, WhatsApp channel with operator approval

Before that, my master's thesis (internship at Smartblue, Rome) was an **AI assistant for contract analysis** — see `ContractRagSystem` below.
